Mission: Rebuild the Electronics Parts Tracker

Flutter & Dart for React + TypeScript Developers

Learn Dart 3, Flutter Widgets, Riverpod, and Freezed by progressively reconstructing a production-grade Electronics Parts Tracker from scratch—anchored at every step to the React and TypeScript mental models you already know.

Course Mission

You already know how to model state with TypeScript interfaces, compose declarative UIs with React function components, manage server/client state with Context, Zustand, or TanStack Query, and verify behavior with React Testing Library.

In this course, you will rebuild the Electronics Parts Tracker (parts_tracker_skilled) step by step inside ./tutorial/apps/. Every lesson pairs one focused slice of the real application with an interactive code exercise, a retrieval quiz, and a runnable companion app verified via flutter analyze and flutter test.

Published Lessons

LESSON 0001 • Bootstrap & ProviderScope
Flutter Bootstrap, ProviderScope & Dark Workbench Shell

Initialize the Parts Tracker foundation: pubspec.yaml, void main(), ProviderScope, StatelessWidget with const constructors, Material 3 dark theme, and your first headless widget test.
LESSON 0002 • Freezed & Domain Models
Immutable Domain Models with Freezed & JSON Serialization

Model Container, Part, and CatalogSnapshot in lib/catalog/catalog_models.dart using @freezed, json_serializable, computed getters, and the 1-to-1 (Container, Slot) lookup.
LESSON 0003 • Persistence Seam & Atomic I/O
Persistence Seam & Atomic Local File Storage

Build CatalogPersistence, InMemoryCatalogPersistence, and FileCatalogPersistence with a serialized Completer write queue, atomic .tmp rename, and backup/export support.
LESSON 0004 • Riverpod AsyncNotifier
Reactive Catalog State with Riverpod AsyncNotifier

Build the Catalog AsyncNotifier with upsertPart, (Container, Slot) uniqueness, quantity clamping, cascading container deletion, all-or-nothing JSON import validation, and ConsumerWidget UI binding.
LESSON 0005 • Unit Search & Derived Providers
Engineering Unit Search Engine & Derived Filter Providers

Implement PartSearchEngine (lib/search/part_search_engine.dart) and reactive workbench filter providers (lib/search/workbench_filter_provider.dart) with @freezed sealed class pattern matching.
